# 實驗環境限制與資料蒐集問題彙整

本文件彙整目前居家實地部署（非受控實驗室環境）過程中，實際遭遇且尚待克服的環境與資料蒐集限制，作為後續資料品質檢討、口試說明與未來改善規劃的參考依據。

---

<a id="sec-1"></a>
## 【1】攝影機架設高度與偵測效果、線材安全之間的取捨

**現象描述**：
攝影機架設過高時，貓咪主體在畫面中的成像角度與比例不利於 YOLO-Pose 模型偵測，導致關鍵點偵測率下降；反之，若降低攝影機架設高度以改善偵測效果，則貓咪活動時容易接觸並啃咬電源線／網路線等外露線材，衍生設備安全與貓咪安全疑慮。

**影響**：
架設高度目前僅能在「偵測品質」與「線材安全」兩者之間妥協取捨，尚無法找到同時滿足兩項需求的理想擺放方案，可能連帶影響原始影像的偵測穩定度與後續關鍵點資料品質。

---

<a id="sec-2"></a>
## 【2】貓咪活動範圍廣、居家空間存在隔牆遮蔽，有效資料量不足

**現象描述**：
受測貓咪的日常活動範圍涵蓋整個居家空間，且室內存在隔牆等遮蔽物，貓咪未必長時間停留於攝影機可拍攝到的範圍內。

**影響**：
單一攝影機視角能實際捕捉到貓咪的時間佔比有限，導致可用於訓練與驗證的有效影像／行為片段明顯不足，資料蒐集效率偏低，也可能造成各行為類別之間的資料量分布不均。

---

<a id="sec-3"></a>
## 【3】飼主生活作息不規律，間接影響貓咪的行為作息模式

**現象描述**：
飼主本身生活作息不固定，時常有熬夜等情形，貓咪的日常作息（如活動、休息時段）會受飼主作息影響而連動改變。

**影響**：
貓咪實際的活動／休息週期缺乏穩定規律性，使得資料蒐集的時間分布較難預期與規劃，也可能導致某些時段（如深夜）拍攝到的行為樣本比例偏高或偏低，影響資料集在時間軸上的代表性。

---

<a id="sec-4"></a>
## 【4】攝影機架設地點 Wi-Fi 訊號強度不足，偶發連線中斷

**現象描述**：
攝影機實際架設位置的 Wi-Fi 訊號強度較弱，於長時間錄製過程中偶爾發生連線中斷的情形。

**影響**：
連線中斷可能導致錄影片段中途遺漏或影像串流短暫停滯，除了直接造成資料缺漏外，也需要額外人工檢查每段錄影的完整性，增加資料前處理與品質確認的成本。

---

<a id="sec-5"></a>
## 【5】攝影機 App／SD 卡影片回放為切片儲存形式，缺乏完整連續錄像

**現象描述**：
目前使用的攝影機 App 與 SD 卡儲存機制，影片是以固定時間長度切片（分段）的形式儲存與回放，而非單一連續完整錄影檔案。

**影響**：
切片儲存可能使原本連續的行為片段被切割在兩個相鄰檔案的交界處，造成行為片段時間軸不連續或首尾資訊缺失；後續若需要跨切片重建完整行為序列，也需要額外的檔案拼接／時間對齊處理，增加資料整理的複雜度與出錯風險。

---

## 小結

以上五項問題共同反映出「居家非受控環境」與「實驗室理想條件」之間的落差：架設條件受限於居家空間安全與網路環境、貓咪行為受限於飼主生活作息與活動範圍、影像資料則受限於攝影機硬體與儲存機制本身的規格。這些限制是解讀目前資料集規模、類別分布與資料品質時應納入考量的背景因素，也是未來規劃資料蒐集策略（如新增攝影機視角、調整錄製排程、更換儲存/回放方案等）時的主要改善方向。
