## 一、為什麼需要這份文獻回顧

[`gcn文獻來源.md`](gcn文獻來源.md) 已經把本專案的 ST-GCN 架構逐一對照到**人體動作辨識**文獻（Yan et al. 2018、Kipf & Welling 2017、2s-AGCN、MS-G3D、CTR-GCN、GAT 等）。但論文口試最常被問到的問題之一會是：

> 「這些技術都是人體動作辨識的文獻，你怎麼知道它們能用在貓身上？有沒有人已經做過動物版本？」

這份文件的任務就是回答這個問題：系統性查證「動物／畜牧／寵物領域的骨架式行為辨識」現況，確認：

1. 骨架式（skeleton-based）方法是否已在動物領域被驗證可行——**答案：是，但集中在畜牧動物（豬、牛），貓咪幾乎是空白**
2. 本專案「未採用清單」中的進階技術（CTR-GCN 動態拓撲、GAT、Transformer）是否已有動物領域的成功案例——**答案：截至查證時間點，尚未發現**
3. 這個空白本身能否構成論文的研究貢獻——**答案：可以，且應明確寫入研究缺口論述**

## 二、動物姿態估計的資料基礎：AnimalPose 與 Animal Kingdom

在討論行為辨識之前，必須先確認「動物骨架關鍵點」這件事本身有沒有文獻基礎（因為本專案的骨架來自 YOLO pose 模型，而非人工標註的動物專用資料集）。

<a id="sec-2-1"></a>
### 2.1 AnimalPose（跨物種姿態估計的奠基資料集）

| 項目 | 內容 |
|------|------|
| **文獻** | Cao, J., Tang, H., Fang, H.-S., Shen, X., Lu, C., & Tai, Y.-W. (2019). *Cross-Domain Adaptation for Animal Pose Estimation*. ICCV 2019. |
| **核心貢獻** | 建立第一個涵蓋五種動物（牛、羊、馬、**貓**、狗）的關鍵點標註資料集，並提出跨域遷移方法，將人體/單一動物的姿態知識遷移到未標註的其他物種 |
| **與本研究的關係** | 直接證明「貓的關鍵點骨架」在學術上是被承認、可行的表示方式；本專案用 YOLO pose 取得貓的關鍵點，概念上與 AnimalPose 的標註格式（COCO 風格）一致，可作為方法論正當性的引用來源 |
| **限制** | 資料集規模小（Part I 五物種合計數千張影像），且是靜態姿態估計（單張圖片關鍵點），不含時序動作標籤，因此**沒有處理「動作辨識」**，只處理「關鍵點偵測」 |

<a id="sec-2-2"></a>
### 2.2 Animal Kingdom（大規模跨物種行為理解資料集）

| 項目 | 內容 |
|------|------|
| **文獻** | Ng, X. L., Ong, K. E., Zheng, Q., Ni, Y., Yeo, S. Y., & Liu, J. (2022). *Animal Kingdom: A Large and Diverse Dataset for Animal Behavior Understanding*. CVPR 2022. |
| **核心貢獻** | 850 種動物、50 小時標註影片、3 萬段動作辨識序列、3.3 萬張姿態估計影格，涵蓋 140 種行為描述；提出 CARe（Collaborative Action Recognition）模型處理跨物種泛化 |
| **與本研究的關係** | 證明「動物行為辨識」在頂級電腦視覺會議（CVPR）已是被承認的研究方向；但其目標是**跨物種泛化**（zero-shot 到未見過的動物），而非針對單一物種（貓）做細粒度、高準確率的行為分類——這正是本研究與其定位不同之處 |
| **限制** | 該資料集雖含貓科動物影像，但未針對貓的家庭室內監控情境（居家環境、近距離俯視角、5 類細粒度行為）做設計，屬於「廣而淺」而非「窄而深」的資料集 |

**小結**：AnimalPose 與 Animal Kingdom 共同確立「動物骨架/行為辨識」是主流電腦視覺研究已涉足的領域，但兩者都不是「貓咪居家行為監控」這種應用導向、細粒度、單一物種深耕的設計，這是第一層研究缺口。

## 三、骨架式行為辨識在畜牧動物的應用：最直接的方法論參照

這是本次查證中**最重要的發現**：雖然沒有查到貓的骨架式行為辨識論文，但**豬與牛的骨架式行為辨識文獻相當成熟**，且架構選擇與本專案高度相似（同樣採用 ST-GCN 骨幹、同樣是小規模資料集、同樣追求即時/輕量部署）。這些文獻應作為本研究方法論最直接的參照與定位基準。

<a id="sec-3-1"></a>
### 3.1 BCST-GCN（豬隻行為辨識，2026 最新）

| 項目 | 內容 |
|------|------|
| **文獻** | Chai, H., Zhan, W., & Su, J. (2026). *BCST-GCN: A Skeleton-Based Spatiotemporal Graph Convolutional Network with Bidirectional Cross-Attention for Pig Behavior Recognition*. Frontiers in Veterinary Science, 13, Article 1782396. |
| **問題意識** | 影像式豬隻行為辨識易受環境雜訊干擾；既有骨架方法無法捕捉非物理相鄰關節的互動，且難以適應動態行為變化 |
| **方法** | 17 個依豬體解剖設計的關鍵點；以 DeepLabCut(ResNet-50) 取得關鍵點；核心創新是「雙向交叉注意力（BC 模組）」：全域自注意力（動態建構非物理相鄰關節依賴）＋局部自注意力（量化一階鄰居的物理連結強度）；並精簡 ST-GCN 層數（參數量從 2.08M 降至 1.98M） |
| **資料規模** | 180 支影片、6,230 關鍵影格，資料增強後 18,690 張影像；4 類行為（進食、行走、臥躺、犬坐）——**規模與本專案量級相近** |
| **成效** | 準確率較基礎 ST-GCN 提升 3.05%（95.36% vs 92.31%）、推論時間減少 18.3%、FLOPs 減少 25% |
| **與本研究的關係** | **這是目前查證到與本專案架構最接近的文獻**：同樣是「ST-GCN 骨幹 + 注意力機制強化 + 小規模動物資料集 + 即時推論導向」。其「雙向交叉注意力」概念與本專案 JointAttention 的差異，可作為論文中「本設計 vs. 更進階動物領域方案」的直接比較對象 |
| **限制（其自陳）** | 僅測試單一豬隻，未解決群養環境下的遮蔽與個體交互問題；「犬坐」與「臥躺」誤判率達 16% |

<a id="sec-3-2"></a>
### 3.2 乳牛骨架式行為辨識（Li et al., 2022；Hua et al., 2023）

| 項目 | 內容 |
|------|------|
| **文獻 1** | Li, Z., Song, L., Duan, Y., Wang, Y., & Song, H. (2022). *Basic Motion Behaviour Recognition of Dairy Cows Based on Skeleton and Hybrid Convolution Algorithms*. Computers and Electronics in Agriculture, 196, 106889. |
| **文獻 2** | Hua, Z., Wang, Z., Xu, X., Kong, X., & Song, H. (2023). *An Effective PoseC3D Model for Typical Action Recognition of Dairy Cows Based on Skeleton Features*. Computers and Electronics in Agriculture, 212, 108152. |
| **核心貢獻** | 兩篇均以骨架特徵取代原始影像做乳牛動作辨識；文獻 2 採用 PoseC3D（將骨架轉為 3D heatmap volume + 3D CNN），YOLOX-Pose 取得關鍵點準確率 96.3%，PoseC3D 辨識 4 類牛隻動作 Top-1 準確率 92.6% |
| **與本研究的關係** | 直接證明「骨架特徵優於原始影像」這個設計選擇在動物領域已被驗證；同時也提供了 [`gcn文獻來源.md`](gcn文獻來源.md#sec-4-6) 中「未採用技術 4.6 PoseC3D」的動物領域反例——PoseC3D 已被證明可用於牛（大型動物、資料量較大的農場監控場景），可在論文「未來優化方向」中引用作為佐證，同時說明貓（小型、居家、即時推論限制更嚴格）與牛（大型農場、可承受較高運算成本）場景差異，解釋為何本專案現階段未採用 |

<a id="sec-3-3"></a>
### 3.3 仔豬社交行為辨識（Gan et al., 2022）

| 項目 | 內容 |
|------|------|
| **文獻** | Gan, H., Xu, C., Hou, W., Guo, J., Liu, K., & Xue, Y. (2022). *Spatiotemporal Graph Convolutional Network for Automated Detection and Analysis of Social Behaviours Among Pre-Weaning Piglets*. Biosystems Engineering, 217, 102–114. |
| **核心貢獻** | 以 GCN 建模仔豬社交行為（鼻對鼻、鼻對身接觸、攻擊/玩耍），是少數處理「多動物互動」而非單一動物行為的骨架 GCN 應用 |
| **與本研究的關係** | 提供「若未來擴充到多貓互動場景」的技術路徑參考，屬於前瞻性引用 |

**小結**：豬與牛的骨架式 ST-GCN／PoseC3D 應用，構成了本研究最直接可引用的「同架構、跨物種」方法論先例。這批文獻的存在，讓論文可以主張：**「骨架式圖卷積方法在畜牧動物行為辨識已獲驗證，本研究將其進一步延伸應用於居家貓咪監控場景，是該技術路線在寵物照護領域的首次系統性應用」**——這是可以立足的 novelty 論述。

### 4.2 中文文獻查證結果

以「貓咪 行為辨識 骨架 深度學習 姿態估計」查證中文學術與技術文獻，**未發現**針對貓咪骨架式行為辨識的中文期刊或會議論文；查得的中文資源多為 CNN 影像分類科普教學文章（貓狗二分類），非行為辨識研究。這進一步支持「中文語境下貓咪骨架行為辨識為空白領域」的判斷。

<a id="sec-4-3"></a>
### 4.3 研究缺口總結

| 缺口層次 | 現況 | 本研究定位 |
|---------|------|-----------|
| **物種缺口** | AnimalPose、Animal Kingdom 涵蓋貓但非以貓為核心；畜牧骨架式 GCN 聚焦豬/牛；貓咪骨架式行為辨識學術文獻**近乎空白** | 首次將 ST-GCN 家族方法系統性應用於貓，並針對貓體結構做客製化骨架設計 |
| **場景缺口** | 既有動物骨架 GCN 文獻多為農場監控（固定攝影機、大型動物、較寬鬆的運算資源） | 居家即時監控場景，強調輕量化、即時推論（呼應 BCST-GCN 的「輕量化」方向，但應用場域不同） |
| **前處理缺口** | 動物姿態正規化多沿用人體骨架文獻（NTU RGB+D 系列）的中心化/軸對齊邏輯（詳見 [`gcn文獻來源.md`](gcn文獻來源.md#sec-2-5) §2.5），但**未見專門針對貓體 2D 俯視角設計的朝向正規化方法** | `flip_normalize()` 是目前查證範圍內**無直接文獻對應**的 domain-specific 設計，可主張為本研究的方法論貢獻之一 |

## 五、「未採用技術」在動物/小資料集領域的應用證據

回應 [`gcn文獻來源.md`](gcn文獻來源.md#sec-4) 第四節「尚未採用的主要技術」，此次查證特別檢視這些技術是否已有動物或小資料集領域的成功前例，作為論文「未來優化方向」章節的文獻佐證：

| 未採用技術 | 動物/小資料集領域應用證據 | 查證結論 |
|-----------|--------------------------|---------|
| **動態鄰接矩陣（CTR-GCN 風格）** | 未查得直接動物領域應用；BCST-GCN 的「全域自注意力動態建構關節依賴」概念上與動態拓撲精神相近，可視為**間接前例** | 弱-中度佐證，可引用 BCST-GCN 作為概念延伸 |
| **圖注意力（GAT 風格）** | 查證範圍內未發現動物骨架領域的 GAT 應用；人體領域的 GCN+Transformer 混合架構（如 GTC-Net、KA-AGTN、MGSAN）近期活躍，但均以 NTU RGB+D 等大型人體資料集驗證 | 無直接動物前例，維持「未採用」判斷的合理性不變 |
| **時空 Transformer** | 同上，未見動物/小資料集領域應用 | 同上 |
| **雙流架構（Joint + Bone）** | 未查得動物領域雙流應用；但骨段特徵（bone feature）本身已被畜牧文獻採用（單流多通道形式，同本專案做法） | 佐證「單流多通道已足夠」的設計選擇，而非雙流 |
| **PoseC3D（體素化骨架）** | **已有明確動物領域前例**：Hua et al. (2023) 於乳牛動作辨識中應用，Top-1 準確率 92.6% | 強佐證，但場景差異需說明（見 [§3.2](#sec-3-2)） |
| **InfoGCN** | 未查得動物領域應用 | 無直接前例 |

**結論**：六項未採用技術中，僅 PoseC3D 已有明確動物領域前例（且是大型動物/農場場景），其餘五項在動物領域仍是空白。這代表：(1) 本研究的技術選型與現有動物領域文獻的技術成熟度大致同步；(2) 論文可以誠實地說明「未採用不是因為技術本身不成熟，而是動物領域對這些技術的驗證仍非常有限，貿然採用風險高於收益」。

## 六、綜合定位論述（建議寫入論文文獻回顧結論段）

> 骨架式時空圖卷積網路（ST-GCN 及其衍生架構）自 Yan et al. (2018) 提出後，已在人體動作辨識領域發展出成熟的技術體系（見 [`gcn文獻來源.md`](gcn文獻來源.md)）。近年此一技術路線開始擴散至動物領域，但應用高度集中於畜牧動物：豬（Chai et al., 2026）、牛（Li et al., 2022; Hua et al., 2023）、仔豬社交行為（Gan et al., 2022）均已驗證骨架式 GCN／PoseC3D 於動物行為辨識的有效性，且部分文獻（BCST-GCN）的問題設定（小規模資料、即時推論需求）與本研究高度相似，可作為方法論參照基準。
>
> 相對地，寵物／貓咪領域的骨架式行為辨識仍近乎空白：現有貓咪深度學習研究以影像分類（品種辨識）、姿勢分類（攻擊性判讀，Sui et al., 2024）、或穿戴式感測器方案為主，尚未見以 ST-GCN 家族方法系統性處理貓咪居家行為辨識的學術文獻；跨物種姿態資料集（AnimalPose, Cao et al., 2019；Animal Kingdom, Ng et al., 2022）雖涵蓋貓科影像，但目標是跨物種泛化而非單一物種深耕。
>
> 本研究站在「畜牧動物骨架式 GCN 已驗證可行」與「貓咪領域尚未系統應用」的交界，將此一技術路線首次系統性延伸至居家貓咪行為監控場景，並針對貓體結構（骨架關鍵點設計）與居家俯視監控情境（朝向正規化 `flip_normalize`）提出 domain-specific 的前處理設計，填補此一研究缺口。
